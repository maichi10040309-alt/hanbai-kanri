# 販売管理 HANBAI

小規模事業者向けの、ブラウザで動く販売管理ソフトです。

## 初期版の機能

- 得意先・商品台帳（CSV入出力）
- 見積書、納品書、請求書、領収書
- 伝票の転記、印刷、PDF保存
- 10%・軽減8%・非課税の消費税計算
- 入金登録と売掛残高
- JSONバックアップ・復元

## 重要

データはブラウザの `localStorage` に保存されます。同じURLでも別のPC・別のブラウザには共有されません。業務利用時は定期的に「自社設定・バックアップ」からバックアップを書き出してください。

本ソフトはBSL社製品とは無関係の独自ソフトです。法令・税制への最終的な適合性は、利用者の責任で確認してください。
